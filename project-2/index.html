Part 1: Fun with Filters

Part 1.1: Convolutions from Scratch

Convolution with zero padding and "same" output size. The padding matches scipy.signal.convolve2d, including for even-sized kernels like Dx = [1, −1]. 

def same_padding_amounts(kh, kw):
    """Padding for (top, bottom, left, right), placed the same way scipy does it."""
    ch, cw = (kh - 1) // 2, (kw - 1) // 2
    return kh - 1 - ch, ch, kw - 1 - cw, cw

def zero_pad(image, top, bottom, left, right):
    h, w = image.shape
    padded = np.zeros((h + top + bottom, w + left + right), dtype=float)
    padded[top:top + h, left:left + w] = image
    return padded

def pad_for_same(image, kernel):
    return zero_pad(image, *same_padding_amounts(*kernel.shape))

def conv2d_four_loops(image, kernel):
    """out[i, j] = sum over m, n of kernel[m, n] * image[i - m, j - n]"""
    kh, kw = kernel.shape
    h, w = image.shape
    padded = pad_for_same(image, kernel)
    out = np.zeros((h, w), dtype=float)
    for i in range(h):
        for j in range(w):
            total = 0.0
            for m in range(kh):
                for n in range(kw):
                    total += kernel[m, n] * padded[i + kh - 1 - m, j + kw - 1 - n]
            out[i, j] = total
    return out

def conv2d_two_loops(image, kernel):
    """Same as the four-loop version, but flips the kernel once and multiplies whole windows."""
    kh, kw = kernel.shape
    h, w = image.shape
    padded = pad_for_same(image, kernel)
    flipped = kernel[::-1, ::-1]
    out = np.zeros((h, w), dtype=float)
    for i in range(h):
        for j in range(w):
            out[i, j] = np.sum(padded[i:i + kh, j:j + kw] * flipped)
    return out

The four-loop version reads the image backward, which is where the minus signs in the convolution formula come from. The two-loop version flips the kernel once instead.

Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening"

Subtracting a blurred copy from an image leaves its fine details (the high frequencies). Adding α times those details back makes the image look sharper. This fits in one filter, the unsharp mask filter: (1 + α) δ − α G, where δ keeps the image unchanged and G is the Gaussian. I used σ = 2 and α = 1.5.

Part 2.2: Hybrid Images

Up close we see an image's fine details; from far away we only see its broad shapes. A hybrid combines the details of one image (the image minus its blur) with the blurred version of another.

I used σ = 5 for the details and σ = 10 for the blur, on images scaled to at most 800 px. That puts the cutoffs at about 0.037 and 0.019 cycles per pixel (where each filter lets half through). The gap between them keeps the two images from overlapping.

I chose these values by trial and error.

Part 2.3: Gaussian and Laplacian Stacks

Each Gaussian level blurs the previous one. Since stacks never shrink the image, I doubled the blur at each level (σ = 2, 4, 8, 16) to act like a pyramid. Each Laplacian level is the difference between two neighboring Gaussian levels, and the last one is the blurriest Gaussian level, so all the levels add back up to the original image.

Part 2.4: Multiresolution Blending

Each Laplacian level is blended using the mask blurred to match that level, then the levels are added up. Fine details meet at a sharp seam while broad color and lighting blend over a wide area, so the seam is hard to see.

What I Learned

Filters can be convolved together into a single filter that does the same thing as applying them one after another. This is how the DoG filters and the unsharp mask filter each do their job in one convolution.
